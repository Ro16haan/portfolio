# Balagouni Rohan Kumar Goud Portfolio

A minimal, responsive portfolio built from the resume details in
`assets/rohan-kumar-goud-resume.pdf`.

## Run Locally

Open `index.html` directly in a browser, or run a tiny static server:

```powershell
python -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.
